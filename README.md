# iFinance

iFinance is a budgeting and stock portfolio management application.

## Stack

* Java 21
* [Maven](https://maven.apache.org) (3.0.0+)
* [Spring Boot](https://spring.io/projects/spring-boot) (4.0.0+)
* [PostgreSQL](https://www.postgresql.org) (42.7.11+)
* [Angular](https://v18.angular.dev/overview) (18+)
* [PrimeNG](https://v18.primeng.org/installation) (18+)
